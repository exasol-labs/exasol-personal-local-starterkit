Each model is scored with the metric for its task. The metric the lab picks by comes first in the table. The board shows the other columns as well.

## Metrics

| Task | The metric the lab picks by | Also on the held-out rows |
|---|---|---|
| Predict yes or no | ROC AUC. PR AUC when the rarer answer is under 5%. | ROC AUC, PR AUC and F1 at a 0.5 cut-off |
| Predict a number | R squared | R squared, mean absolute error (MAE) and root mean squared error (RMSE) |
| Find natural groups | Silhouette score: how well each row fits its own group compared with the next one | The number of groups tried, and the score for each |
| Find unusual rows | None is scored. You set the share to flag (`contamination`, 2% by default). | The flagged count, the share, and what sets the flagged rows apart |

In plain words:

- **ROC AUC** is the chance that the model gives a row with a 1 a higher score than a row with a 0. It is explained on [Reading ROC AUC](/data-scientist/evaluate/roc-auc).
- **PR AUC** is the average precision score: how well the model's top-ranked rows contain the rare 1s. It is the one to read when 1s are rare.
- **F1** combines how many flagged rows are right and how many real 1s are found, at one cut-off (0.5 here).
- **R squared** is the share of the spread in the number that the model explains. A value of 0 means no better than the average.
- **MAE** is the average size of the miss, in the number's own units. **RMSE** is similar, but it punishes large misses more.
- **Silhouette score** is how close each row sits to its own group, compared with the nearest other group.

## The columns on the board

- `cv` is the mean cross-validated score for the metric the lab picks by.
- `cv_sd` is how much that score varies across folds. Read it before you compare two models.
- `held` is the held-out score for the same metric.

The board's other columns (`roc_auc`, `pr_auc`, `f1`, `r2`, `mae`, `rmse`) are the held-out values for each model.

```python
lab.board    # one row per model: cv, cv_sd, held, and the other held-out metrics
```

---
title: Run the kit from a notebook
description: Check, update and extend the kit without leaving the notebook.
---

Step 0 of the quickstart is the kit itself. Every command here is the same `exakit` a terminal runs, with its output streaming into the cell.

## See what is there

```python
kit_state = nb.kit_check()      # what is installed and running; changes nothing
nb.components()                 # the kit's parts, their versions and pending updates
nb.addons()                     # the marketplace's add-ons and their state
nb.sample_datasets()            # the kit's datasets, and which are loaded
nb.loaded_files()               # the files you loaded
nb.notebooks("data-scientist")  # this persona's notebooks, in order
```

## Change it

```python
nb.exakit("start")                                  # start the database
nb.addon_ready("dash-server")                       # install and start an add-on
nb.exakit("data-load", "fraud_transactions")        # load a kit dataset, a file or a folder
nb.exakit("logs", "dash-server")                    # a service's log
nb.kit_update()                                     # bring the kit and its add-ons up to date
```

`nb.exakit(...)` returns the run with its exit code, so a cell can act on it.

<Callout>

A command run from a cell has no terminal, so a question it would ask takes its default. Give a choice up front instead: `nb.exakit("mcp-setup", env={"EXAKIT_MCP_CLIENTS": "claude"})`.

</Callout>

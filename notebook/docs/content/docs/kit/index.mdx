The Exasol Personal Local Starter Kit installs a database on this computer and the tools around it. One command, `exakit`, runs all of it.

## What every install has

| Part | What it is for |
|---|---|
| The database | Exasol, running on this computer |
| `exakit` | The command that starts, checks, loads and updates everything |
| The AI bridge | Lets your AI clients query the database, read-only |
| AI skills | Instructions that teach an AI client how to use the kit |
| Sample data | Datasets to practise on |

## What a persona adds

A **persona** is the kit set up for one kind of work. It decides which datasets are loaded, which add-ons are installed and which notebooks you get. See [What is a persona](/kit/personas/what-is-a-persona).

## Help on this computer

```bash
exakit help                # every command
exakit help data-load      # one command in full
exakit catalog load        # search the commands
exakit status              # is the database up?
```

The same help is built into the kit, so it always matches the version you have.

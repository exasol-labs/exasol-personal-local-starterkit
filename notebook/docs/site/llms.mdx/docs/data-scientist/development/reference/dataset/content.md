
The rules are the kit's descriptor rules (`descriptor_rules`, shipped with this package: the 0.2 kit has no Python
package to import them from). It is a copy of tools/descriptor_rules.py, which tools/dataset_check.py uses, and
tests/test_notebook_contents.py holds the two byte-identical. Nothing is guessed: a descriptor that is invalid, or
names a table or column the database lacks, stops the notebook with the reason.

Which descriptor a name resolves to, in order: a path given (a file, or a folder holding descriptor.yaml); for a
data file of your own, `<name>.descriptor.yaml` beside it; for an id, the approved version in the kit's store
(`~/.exasol-starter-kit/descriptors/<SCHEMA>.<TABLE>/current.yaml`, or an older kit's `descriptors/<id>/current`;
descriptor_store), then the descriptor the kit ships under
`data/datasets/<id>/`. `ds.descriptor_path` and `ds.descriptor_origin` say which one was used.

## nb.Dataset [#Dataset]

```python
class nb.Dataset
```

A validated descriptor whose every role the database holds, with the SQL names the notebooks build queries from.

| Member                                      | What it is                                                                                                                                                                                                                                                      |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                                        | `str`                                                                                                                                                                                                                                                           |
| `path`                                      | `Path`                                                                                                                                                                                                                                                          |
| `digest`                                    | `str`                                                                                                                                                                                                                                                           |
| `descriptor`                                | `Any`                                                                                                                                                                                                                                                           |
| `descriptor_path`                           | \`Path                                                                                                                                                                                                                                                          | None\` |
| `descriptor_origin`                         | `str`                                                                                                                                                                                                                                                           |
| `fact_table`                                | `SCHEMA.TABLE` that one row of analysis comes from.                                                                                                                                                                                                             |
| `source`                                    | The external source's alias when the table is in a virtual schema (a live source), else None - what confirm_send and the quickstart ask about.                                                                                                                  |
| `source_ref`                                | The descriptor's `source` as written: a dataset id, `file:<path>`, `vs:<alias>` (or a schema_version 1 file's bare alias), or None.                                                                                                                             |
| `version`                                   | The descriptor's version: 1 for a first draft or a shipped file; approving writes the next.                                                                                                                                                                     |
| `status`                                    | `draft` (proposed, not yet confirmed) or `approved`.                                                                                                                                                                                                            |
| `owner`                                     | Who drafted or approved it (`kit` for a shipped descriptor).                                                                                                                                                                                                    |
| `created`                                   | When this version was written (ISO-8601), None for a schema_version 1 file.                                                                                                                                                                                     |
| `table_digest`                              | The digest of the table the descriptor was approved on (its `digest` key, design 2.3: sha256 over the table's name, its columns and types, the row count and an order-independent content hash of the role columns), None until approve computes it.            |
| `current_table_digest(conn) -> str`         | The table's digest as it is now, computed the way approve computed `table_digest`; a value that differs from `table_digest` means the data changed since the descriptor was approved (a virtual table's digest covers its first sample rows and the row count). |
| `drafted_by`                                | `profile` (exakit describe), `shipped` (the kit) or `user` (roles given by hand).                                                                                                                                                                               |
| `evidence`                                  | Per role, the numbers that chose its column (what the profiler recorded; empty for roles given by hand).                                                                                                                                                        |
| `notes`                                     | Per column, a model-written line about it (never decisive; empty without a model).                                                                                                                                                                              |
| `missing`                                   | The roles no column fits, each `{role, reason}`; the notebooks skip what depends on them with the reason.                                                                                                                                                       |
| `require_approved(purpose: str) -> Dataset` | This dataset when its descriptor is approved; a draft raises DescriptorNotApproved saying how to approve it.                                                                                                                                                    |
| `col(role: str) -> str`                     | The column of a single-column role (entity, category, date, label).                                                                                                                                                                                             |
| `text_cols() -> list[str]`                  | The text columns, in the descriptor's order; none when no column plays the text role.                                                                                                                                                                           |
| `text_sql() -> str`                         | One SQL expression joining the text columns with a space, NULLs as empty; a dataset without text raises ValueError with the descriptor's reason.                                                                                                                |
| `roles() -> list[tuple[str, str]]`          | (role, SCHEMA.TABLE.COLUMN) for every role, for a table the notebook prints.                                                                                                                                                                                    |
| `has(role: str) -> bool`                    | Whether a column plays `role` (False for one listed under `missing`).                                                                                                                                                                                           |
| `group_by() -> tuple[str, str]`             | (role, column) the overviews count rows by: the category, else the entity, else the target - a table with only a key, a text and a 0/1 target has no other group, and counting by that target is its overview.                                                  |
| `tags() -> dict[str, str]`                  | What a trace or an MLflow run records about the data: the dataset and the descriptor's digest (and the source's alias for a live source).                                                                                                                       |

## nb.dataset [#dataset]

```python
nb.dataset(conn, name: str | Path) -> Dataset
```

The dataset `name`, checked against the database: a kit dataset id, a descriptor file or its folder, or a data
file of your own (CSV, Parquet or JSON) with its descriptor beside it, which is loaded first (load_own_file).

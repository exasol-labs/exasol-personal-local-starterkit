Themes in text (AI)

What the texts on each side of the label are about, read by your model and traced to your Langfuse.

One model call per side (label = 1, label = 0): the model sorts that side's texts into two to four themes and answers in JSON, so the result is a table - theme, how many texts, their share, an example - with a note in plain words under it. A theme found on one side only is the clue: what those texts are about that the others are not.

With Langfuse set up (nb.trace), both calls are one trace, explore-themes, each call named after its side, with what was sent, the answer, tokens, cost and time, and two scores to compare models and runs by: valid_json (1 when every answer could be read) and texts_placed (the share of texts the model gave a theme).

nb.themes

Sort each side's texts into themes with endpoint = (client, model) from nb.model_client(); return the table (a pandas DataFrame when pandas is there, else a list of rows) and print the note. None without an endpoint.

Used in: data-scientist/01_explore
